# Модуль 2: PWA (веб-интерфейс)

## Запуск

### Вариант 1 — вместе со всей системой (рекомендуется)
```bash
docker compose up -d --build
```
Откройте **http://localhost:5173**. Так как `GOOGLE_CLIENT_ID` пока не задан, на странице входа будет форма **Dev sign-in**: введите `admin@lab.test` (админ) или любой другой email (обычный пользователь) — при `DEV_MODE=true` в `.env` бэкенда.

### Вариант 2 — локальная разработка с горячей перезагрузкой
```bash
cd pwa
cp .env.example .env
npm install
npm run dev          # http://localhost:5173
npm test             # тесты утилит (vitest)
npm run typecheck    # проверка типов
```

## Установка на телефон
1. Откройте сайт в мобильном браузере (обязательно по **HTTPS** или на `localhost`).
2. Android/Chrome: меню → «Установить приложение» / «Добавить на главный экран».
3. iOS/Safari: «Поделиться» → «На экран Домой».

## Что реализовано (по ТЗ 2.3–2.7)
- **Главная**: крупные кнопки всех сценариев; регистрация и админка — только у админов.
- **Поиск**: debounce 300 мс, «часто используемые» (топ-5 общих + топ-3 личных), фильтр категории, упаковка отсортированы по FEFO.
- **Списание**: логика по `tracking_mode` (free — отметка не нужна; per_unit — [1][5][10][другое]; by_measure — [~1/4][~1/2][~3/4][ввести количество] как доля от номинала), отображение гранта «КОД (руководитель)», выбор гранта списания.
- **Размещение/перемещение**: цикл «сканировать упаковку → сканировать место → подтвердить зону → следующая»; работает и для `pending`, и для переноса между лабораториями.
- **Вскрытие**: подтверждение + обязательное сканирование нового места.
- **Регистрация (админ)**: поиск/создание номенклатуры, данные партии, печать этикеток через генератор кодов, подтверждение наклейки сканированием.
- **Будущие закупки**: статусы, заявка, приёмка с разбиением на упаковки, отмена.
- **Мои остатки**, **связка с Telegram** (код + автоожидание), **админ-панель** (таблицы, фильтры, CSV-экспорт, смена `tracking_mode` с подтверждением, отчёт по гранту).
- **Сканер**: `@zxing/library`, QR + DataMatrix, рамка, вспышка, звук + вибрация при успехе.
- **Deep links**: `/package/{id}?action=write-off|open|move|details`.
- **PWA**: манифест, установка, service worker (кэш статики), офлайн-очередь списаний с автодосылкой.
- **Авторизация**: Google (GIS) + авто-продление токена; при отсутствии Client ID — форма входа для разработки.

## Известные упрощения
- Камера доступна только по HTTPS или на `localhost` (ограничение браузеров).
- «Мои остатки» строятся из транзакций за 30 дней.
- Печать этикеток вызывается напрямую из PWA в генератор кодов (см. решения Модуля 4).
